# FreeFollowersTik

FreeFollowersTik is a creator promotion platform.

## Project Structure

- `frontend/` — Website interface
- `backend/` — API and server
- `database/` — Database-related files
- `shared/` — Shared code and types

## Main Features

- User registration
- TikTok Login
- 30-coin welcome bonus
- Coin wallet
- Earn coins
- Creator promotion
- Buy coins
- Payment verification
- Dashboard
- Admin panel
- Ads
- Security and anti-fraud
